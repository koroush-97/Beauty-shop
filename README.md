# 💄 BeautyShop

A modern **beauty & fashion e-commerce UI project** built with React and TypeScript.

---

## ✨ About the Project

**BeautyShop** is a frontend e-commerce project for selling beauty products and clothing.  
It focuses on a clean UI, reusable components, and a scalable architecture.

This project is built as a practice to improve frontend skills and real-world development structure.

---

## 🚀 Tech Stack

This project is built using modern web technologies:

### 🧠 Core
- ⚛️ React 19
- ⚡ Vite
- 🟦 TypeScript

### 🎨 Styling
- 🌈 Tailwind CSS

### 🔀 Routing
- 🧭 React Router DOM

### 🎯 Icons
- 🎨 React Icons
